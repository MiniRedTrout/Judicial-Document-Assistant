# Ручная проверка фронта

Запустите сервер и откройте http://127.0.0.1:8000/ . После обновления кода нажмите Ctrl+F5. Используйте обезличенные примеры. Зафиксируйте результат каждого пункта; эта инструкция не утверждает, что все проверки уже выполнены.

Проверка CSV в Excel: «Данные → Из текста/CSV», UTF-8, разделитель запятая. Для ИНН/СНИЛС/номеров выбирайте тип «Текст». Свёрка полей с оригиналом и эталонной таблицей обязательна для оценки точности.

Проверка отправки пока отдельно: сотрудник проверяет получение/спам и вложение. Для повтора после SENT используйте новую загрузку, не обходите защиту от дублей.

Если возникают ошибки: скриншот фронта + текст traceback из терминала без ключей/паролей. HTTP 200 при регулярном GET /api/documents — нормальное обновление списка.
